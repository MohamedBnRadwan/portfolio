# Mohamed Radwan Portfolio

A personal portfolio website for **Mohamed Radwan**, a Full-Stack .NET Developer.

## Overview

This repository contains a lightweight static website that highlights:

- Professional summary
- Core technical skills
- Contact information
- Work experience
- Projects and certifications sections
- Quick action links (Email, Phone, LinkedIn, GitHub, and Chat page)

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript

## Project Structure

- `index.html` – Main portfolio landing page
- `chat.html` – Secondary chat page
- `include/` – Shared CSS/JS assets
- `images/` – Logos, favicons, and image assets
- `Mohamed-Radwan-Full-Stack-DotNet-Developer.pdf` – Resume PDF

## Run Locally

Because this is a static site, you can run it with any simple local server.

### Option 1: Python

```bash
python3 -m http.server 8000
```

Then open: <http://localhost:8000>

### Option 2: VS Code Live Server

Open the project in VS Code and start **Live Server** from `index.html`.

## Customization

To personalize or extend the portfolio:

1. Update content in `index.html`
2. Modify styles in `include/style.css`
3. Add interactions in `include/script.js` or `include/js/`
4. Replace assets in `images/`
